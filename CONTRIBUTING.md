# Contributing to Visit Wolaita

Thank you for your interest in contributing!

## Development Setup

1. Fork the repository
2. Clone: git clone https://github.com/YOUR_USERNAME/Visit-Wolaita.git
3. Install: npm install
4. Dev server: npm run dev (http://localhost:3000)

## Code Style

- 2-space indentation
- BEM-inspired CSS class naming
- Keep CSS variables in :root block
- Prefer vanilla JS, no frameworks

## Commit Convention (Conventional Commits)

- feat: new feature
- fix: bug fix
- style: CSS/visual changes
- docs: documentation
- perf: performance
- a11y: accessibility
- seo: SEO improvement
- refactor: code refactoring
- config: configuration

## Reporting Bugs

Open a GitHub Issue with reproduction steps, expected vs actual behavior, browser/OS info.
